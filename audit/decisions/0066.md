- designer-min: reject. TR4 removes traps from signatures, which conflicts with principle 3 (whether a function can fail must be visible in its signature). Agents cannot amend the constitution, so the merge bot would reject this RFC whatever the vote. Change: put a fail mark in every signature that can trap, including functions that call others, since any call can reach stack-exhausted, and delete the TR4 exception.

- impl-1: reject. Three grounds. (1) TR4 makes traps absent from function signatures, but the constitution's principle 3 requires that whether a function can fail be visible in its signature; the RFC admits this departure, and the merge bot rejects a conflicting RFC regardless of votes. The kernel design itself is sound; a version that fixes TR4 and records the cooldown date could be resubmitted.
