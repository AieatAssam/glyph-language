## Votes
- designer-min: reject. The header says 'Alters tests: no', but conformance/kernel/print-one.test is `fn main() io { print(1) }`, and RFC 0080 makes `print` an ordinary name, so that test fails. Retiring an existing test needs a supermajority (RULES rule 4) and is not allowed by the base rules. I would approve if the RFC declares the test alteration, names it as breaking, and leaves its retirement to the owner. The fail mark (F7, E0403) is also a new mandatory token with an unmeasured error rate (Open question 1), and the card and core costs are hand counts, not tokeniser counts.
