Findings for RFC 0037 (text-order).

1. Contradicts kernel RFC 0085: OR1, OR3 and OR6 give `<` Text operands and OR5 keeps Text equality, but 0085 E3 makes `<` Int-only, gives Text no equality, and has no Text type (T3). A text ordering RFC must first say what Text is, against the current kernel.
2. Amends RFC 0020 E4 and 0035 TX7, which are superseded; name the current kernel instead.
3. Test plan uses `print`; the builtin is `put`.
4. Cost section states that `spec/` is absent and misquotes `spec/errors.json`; check the files.
Re-propose only after the new kernel is accepted, against its syntax.
