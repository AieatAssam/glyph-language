Findings for RFC 0050 (diagnostic-style-v2).

1. Zero-padded codes are fixed width for human eyes: `"E0006"` to `"E6"` saves one token per record (250 to 244 over 6 records). Keep the numeric blocks.
2. Keep the gate's keys and shapes (`code`, `span.start`, `span.end`, `fix.span`, `fix.replacement`); a `[start,end]` array would save more but breaks the gate contract.
3. Section 5 and kernel RFC 0085 TR1 disagree on the trap line and exit code. Define the one trap form (and exit code) the kernel must use.
