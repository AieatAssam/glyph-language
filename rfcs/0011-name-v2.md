# RFC 0011: The language name

Class: language
Slug: name-v2

## Summary

The language is called **Glyph**. Source files end in `.gl`. The compiler command is `glyphc`. This RFC adds no grammar, no types and no runtime behaviour. It fixes the name, the source-file suffix, and the one diagnostic code, `E0010`, that the suffix rule reports.

## Motivation

The repository already calls the language Glyph in `README.md`, `docs/SPEC.md`, `bin/glyphc` and the site. Keeping that name changes no file. A new name would.

The check job and the publisher must recognise language sources by one fixed suffix, so the suffix is fixed here.

The suffix rule runs on the path before the file is read. It therefore works when the content is not valid Glyph, which is why its code sits in the lexical block `E0001` to `E0099`.

## Design

Normative.

1. The language name is `Glyph`. The spec title is `Glyph`. `Glyph` is the only spelling of the name in the spec, and it is case-sensitive.
2. A source file has the suffix `.gl`, in lower case. A path is a source file when the part after its last `/` is a name with at least one character before a final `.gl`. Case matters. `a.b.gl` and `main.gl` are source files. `main.glyph`, `prog.txt`, `PROG.GL`, `main.gl.bak`, `.gl`, `dir/` and the empty string are not.
3. The compiler executable is `glyphc`. Its subcommands are `check`, `run` and `build`. Later RFCs define them.
4. When `glyphc` is given a path that is not a source file, it does not read the file. It writes exactly one diagnostic record, as RFC 0004 section 2 defines, to stderr, and exits with status 1. Nothing goes to stdout. The record is:
   - `code`: `E0010`
   - `severity`: `error`
   - `message`: `source file does not end in .gl`
   - `span`: `{"file": <path as given>, "start": 0, "end": 0, "line": 1, "column": 1}`
   - no `fix` key.
5. `E0010` has this catalogue entry in `spec/errors.json`: message `source file does not end in .gl`, meaning `the path given is not a source file`. The message is one sentence under RFC 0004 section 2, because a full stop inside a file name is part of the name and not a sentence break.

## Alternatives

- **Keep "Glyph" as a codename and choose a name later.** Rejected. It postpones a decision that costs nothing now and leaves the suffix open.
- **Choose another name.** Rejected. Every existing file and tool would change. Collision with other software was not checked; a later RFC can rename the language if one is found.
- **No suffix rule.** Rejected. The check job and publisher need one suffix to find sources.
- **Accept `.glyph` as well as `.gl`.** Rejected. Two suffixes for one thing break principle 1.
- **Use a `GLY` code prefix.** Rejected. RFC 0004 fixes the form `E` followed by four digits.

## Cost

Counted with `tools/check/tokens.py`.

- **Core spec adds:** the title and the suffix and command rules, as in Design 1 to 4. The counted text is a title line and two paragraphs, 68 tokens.
- **Core spec removes:** nothing.
- **Catalogue entry `E0010`:** 34 tokens in `spec/errors.json`.
- **Spec card:** adds the title line `Glyph` and the line `Source: *.gl, compiler glyphc`, 10 tokens. The card stays far under its 2,000-token cap.
- **Example programs:** this RFC adds no program. Its only program-like text is the diagnostic record in Design 4.
- **Grammar:** no production is added, so grammar coverage is unchanged.
- **Diagnostics:** one code, `E0010`. It is new, and no code is reused.

## Test plan

- **run:** `conformance/name/run-title.test`. A `main.gl` program using the kernel `print` writes `Glyph` to stdout and exits 0.
- **compile-error (node):** `compiler/stage0/src/cli.test.ts`. For each of `prog.txt`, `PROG.GL`, `main.glyph` and `missing.txt`, each of `check`, `run` and `build` writes exactly the Design 4 record to stderr, exits 1, writes nothing to stdout, and does not read the file.
- **accepted message (node):** `compiler/stage0/src/message.test.ts`. The message in Design 4 passes the RFC 0004 message rules.

The conformance runner gives every source the name `main.gl`, so it cannot give `glyphc` a path that is not a source file. The file-name rule is therefore tested by node tests, not by `conformance/` files.

No grammar production is added, so the coverage script has nothing new to match.

## Memory allocation

Not applicable. This RFC adds no heap values.

## Open questions

- Whether a second source suffix is ever wanted. This RFC allows only `.gl`. A later RFC must justify any second suffix.
- Whether the name collides with existing software or trademarks. This was not checked and needs a check outside this RFC.
