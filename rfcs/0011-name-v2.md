# RFC draft: The language name

Class: language
Slug: name-v2
Author: designer-min
Status: draft

## Summary

The language is called **Glyph**. Source files end in `.gl`. The compiler command is `glyphc`. This RFC adds no grammar, no types and no runtime behaviour. It fixes the name in the spec title, the source file extension, and the one diagnostic code that the extension rule uses.

## Motivation

The repository already uses the name Glyph in `README.md`, `docs/SPEC.md`, the compiler command `bin/glyphc` and the site. The cheapest name is the one in use.

The check job and the publisher need one fixed suffix to recognise language sources. The extension rule runs on the file name before the file is read, so it works even when the content is not valid Glyph. That is why it is a file-name rule, even though its code sits in the lexical block.

## Design

Normative.

1. The language is named `Glyph`. The spec title is `Glyph`. Names are case-sensitive, and `Glyph` is the only spelling. The first PR that creates `spec/` removes the word "codename" from `README.md`.
2. A source file is a path whose last suffix is exactly `.gl`, in lower case. The part before the suffix is not empty. Only the part after the last `/` is tested. So `main.gl`, `dir/prog.gl` and `a.b.gl` are source files. `main.glyph`, `prog.txt`, `PROG.GL`, `main.gl.bak`, `.gl`, `dir/` and the empty string are not.
3. The compiler executable is `glyphc`. Its subcommands are `check`, `run` and `build`. This RFC names them and does not define them.
4. When `glyphc check`, `run` or `build` is given a path that is not a source file, it does not read the file. It writes exactly one record, as defined by RFC 0004 section 2, to standard error, and exits with status 1. It writes nothing to standard output. The record is:
   - `code`: `E0010`
   - `severity`: `error`
   - `message`: `source file does not end in .gl`
   - `span`: `{"file": <path as given>, "start": 0, "end": 0, "line": 1, "column": 1}`
   - no `fix`
5. `spec/errors.json` has the entry `E0010` with the message in item 4 and the meaning "the path given is not a source file". Codes are never reused.
6. Under the RFC 0004 message rules, a full stop inside a file name, such as in `.gl`, is not a sentence break. The message in item 4 is valid.

## Alternatives

- **Keep "Glyph" as a codename and choose a name later.** Rejected. It leaves the extension question open and costs nothing to decide now.
- **Another name.** Rejected. Every file and tool would change, and no reason outweighs that. Renaming stays cheap until a release exists.
- **No extension rule.** Rejected. The publisher and check job need one suffix to find sources.
- **Also accept `.glyph`.** Rejected. A second suffix is a second way to name one thing, which breaks principle 1.
- **A `GLY` code prefix.** Rejected. RFC 0004 fixes the form `E` plus four digits.

## Cost

Counted with `tools/check/tokens.py`:

- Message `source file does not end in .gl`: 8 tokens.
- Card line `Source: *.gl, compiler glyphc`: 8 tokens.
- Core spec: the name, the extension rule, the `glyphc` line and the `E0010` entry are added. The implementing PR reports the core spec token count from `tools/check/tokens.py`. This RFC does not estimate it.
- Removes: nothing.
- Grammar: no production is added.
- Diagnostics: one code, `E0010`, the only code this RFC adds.

## Test plan

- **compile-error (node):** `compiler/stage0/src/cli.test.ts`. For each of `check`, `run` and `build`, given `prog.txt`, `PROG.GL`, `main.glyph` and `missing.txt`: stderr is exactly the record in Design item 4 with the path as given, exit status is 1, stdout is empty, and no ENOENT is reported. The conformance runner writes every input to `main.gl`, so these cases cannot be conformance tests.
- **node:** `compiler/stage0/src/source-file.test.ts`. `isSourceFile` gives the results listed in Design item 2.
- **node:** `compiler/stage0/src/e0010.test.ts`. `spec/errors.json` has exactly one `E0010` entry, its code is in the block `E0001` to `E0099`, and `checkMessage` from `compiler/stage0/src/message.ts` returns no problems for its message.
- **run:** `conformance/name/run-title.test`. A `main.gl` prints `Glyph` with the output form of the kernel RFC in force. The test waits until a kernel RFC is in force.

## Memory allocation

Not applicable. This RFC adds no heap values.

## Open questions

- A second source extension is not allowed. A later RFC must justify any second suffix.
- The name is not checked against existing software or trademarks. That needs a network check outside this session.
- The conformance runner cannot vary the input file name. Until it can, E0010 is covered only by the node tests above.
- RFC 0005's address example `main.glyph::add` does not fit Design item 2. Its form under this RFC is `main.gl::add`. This RFC does not edit RFC 0005.
