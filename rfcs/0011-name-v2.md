# RFC draft: The language name

Class: language
Slug: name-v2

## Summary

The language is called **Glyph**. Source files end in `.gl`. The compiler is `glyphc`. This RFC adds no grammar, no types and no runtime behaviour. It fixes the name, the source-file suffix, and the one diagnostic code that the suffix rule uses.

## Motivation

The repository already calls the language Glyph and the compiler `glyphc`. Keeping that name costs nothing; a rename would touch every file. The build and check tools need one fixed suffix to recognise sources before any lexer exists, so the suffix rule is a file-name rule. It runs before the file is read, so it works when the content is not valid Glyph.

## Design

Normative.

1. The language is named `Glyph`. The spec title is `Glyph`. The name is case-sensitive; `Glyph` is the only spelling.
2. A path is a source file when its last component (the part after the last `/`) ends in `.gl` and has at least one character before `.gl`. The match is case-sensitive. These are source files: `main.gl`, `dir/prog.gl`, `a.b.gl`. These are not: `main.glyph`, `prog.txt`, `PROG.GL`, `main.gl.bak`, `.gl`, `dir/`, and the empty string.
3. The compiler executable is `glyphc`. Its subcommands `check`, `run` and `build` are named here. Later RFCs define them.
4. When `glyphc` is given a path that is not a source file, with any subcommand, it does not open the file. It writes one record to standard error and nothing to standard output, then exits with status 1. The record is `{"code":"E0010","span":{"start":0,"end":0}}` followed by LF, in the form RFC 0112 D1 to D3 defines. The span is the start of the file, because the file is not read. The record has no `fix`.
5. Code `E0010` is in `spec/errors.json` as `{"code":"E0010","message":"source file does not end in .gl","meaning":"the path given is not a source file"}`. The message meets RFC 0112 D6. A full stop inside `.gl` is part of a file name, not the end of a sentence.

## Alternatives

- **Keep "Glyph" as a codename and fix the suffix later.** Rejected. It leaves the suffix question open, and tools need it now.
- **A different name.** Rejected. Every existing file and tool would change, and no reason outweighs that. Trademark and name clashes are not checked here. Renaming stays cheap until a release exists.
- **No suffix rule.** Rejected. Tools need one suffix to find sources.
- **Accept `.glyph` as well as `.gl`.** Rejected. A second suffix is a second way to name the same kind of file.
- **Another code prefix or block.** Rejected. RFC 0112 D2 fixes the form `E` plus four digits. RFC 0004 section 4 puts lexical codes in `E0001` to `E0099`, and `E0010` is the next free code there.

## Cost

Counted with `tools/check/tokens.py`:

- Core spec: adds the spec text for the name, the suffix rule, `glyphc` and E0010, which is 96 tokens.
- Spec card: adds `Glyph` and `Source: *.gl, compiler glyphc`, which is 10 tokens.
- Removes: nothing.
- Diagnostics: one code, `E0010`. The record shape is RFC 0112's; this RFC adds no record field.
- Grammar: no production is added, so grammar coverage is unchanged.
- Example program in the run test, `main io{put"Glyph"}`: 7 tokens.

## Test plan

Conformance tests (kind `run` and `compile-error`):

- `conformance/name/run-title.test` (run): source `main io{put"Glyph"}`. Expected stdout `Glyph` and exit 0. Syntax and `put` are those of RFC 0109 (kernel-v47), with the lexical rules of RFC 0104.
- `conformance/name/bad-extension.test` (compile-error): meta `input: prog.txt`. Running `glyphc check prog.txt` gives exactly `{"code":"E0010","span":{"start":0,"end":0}}`, no `fix`, exit 1, and nothing on stdout. The runner compares `code`, `span` and `fix`.
- `conformance/name/upper-extension.test` (compile-error): meta `input: PROG.GL`. Same expected record, exit 1.

Node tests, run by the existing `compiler/stage0/**/*.test.ts` gate:

- `compiler/stage0/src/source-file.test.ts`: every path in Design 2 is classified as stated.
- `compiler/stage0/src/cli.test.ts`: for `check`, `run` and `build`, each of `prog.txt`, `PROG.GL`, `main.glyph` and a missing `missing.txt` gives exactly the record in Design 4, exit 1, nothing on stdout, and no file-open error.

No grammar production is added, so the coverage script has nothing new to match.

## Memory allocation

Not applicable. This RFC adds no heap values.

## Open questions

- Whether a later RFC should accept a second suffix. This RFC says no. A later RFC that adds one must remove or justify the `.gl` rule.
