# RFC draft: The language name

Class: language
Slug: name-v2
Author: designer-min

## Summary

The language is called **Glyph**. Source files end in `.gl`. The compiler command is `glyphc`, as already used in `bin/glyphc`. This RFC adds no grammar, no types and no runtime behaviour. It fixes the name in the spec title, the one source file extension the toolchain needs, and the one diagnostic code that rule uses.

## Motivation

The repository already calls the language Glyph in `README.md`, `docs/SPEC.md`, the compiler command and the site. The cheapest name is the one already in use.

The check job and the publisher need one fixed suffix to recognise language sources, so the suffix is fixed here.

The source-file check runs on the path before the file is read. It works even when the content is not valid Glyph. That is why it is a path rule, even though its code sits in the lexical block.

## Design

Normative.

1. The name of the language is `Glyph`. The spec title is `Glyph`. `README.md` does not call Glyph a codename.
2. A source file has the extension `.gl`, in lower case. A path is a source file when the part after its last `/` ends in `.gl` and has at least one character before `.gl`. The match is case-sensitive. These are source files: `main.gl`, `dir/prog.gl`, `a.b.gl`, `dir/.x.gl`. These are not: `main.glyph`, `prog.txt`, `PROG.GL`, `main.gl.bak`, `.gl`, `dir/.gl`, `dir/` and the empty string.
3. The compiler executable is `glyphc`. Its subcommands are `check`, `run` and `build`. This RFC does not define what they do; later RFCs do.
4. `Glyph` is the only spelling of the name in the spec.
5. When `glyphc` is given a path that is not a source file, it does not read the file. It writes one JSON Lines record to standard error, as RFC 0004 section 2 defines, and nothing to standard output. It exits with status 1. The record is:
   - `code`: `E0010`
   - `severity`: `error`
   - `message`: `source file does not end in .gl`. A full stop inside a file name is not a sentence break under RFC 0004 section 2.
   - `span`: `{"file": <path as given>, "start": 0, "end": 0, "line": 1, "column": 1}`. The file is not read, so the span is the start of the file.
   - no `fix`. Renaming the file is the author's choice, not a mechanical edit.
6. `E0010` is listed in `spec/errors.json` with the message above and the meaning "the path given is not a source file". Codes are never reused.

## Alternatives

- **Keep "Glyph" as a codename and pick a new name later.** Rejected. It postpones a decision that costs nothing now and leaves the extension question open.
- **Pick a new name.** Rejected. Every existing file and tool would need changing. Collision with other projects was not checked, because this session has no network access. A later RFC can rename the language; renaming is cheap until a release exists.
- **No file extension rule.** Rejected. The publisher and check job need one suffix to find sources.
- **Accept `.glyph` as well as `.gl`.** Rejected. A second suffix is a second way to name the same thing, which breaks principle 1.
- **A `GLY` code prefix.** Rejected. RFC 0004 section 2 fixes `E` followed by four digits.

## Cost

Counted with `tools/check/tokens.py`:

- **Core spec:** the title and the rule, `Glyph. Source file: last suffix exactly .gl, lower case. Other paths are not read: E0010, exit 1.`, count 28 tokens. No grammar production is added.
- **Spec card:** the two lines `Glyph` and `Source: *.gl, compiler glyphc`, count 10 tokens. The card stays far under its 2,000-token cap.
- **Diagnostic message:** `source file does not end in .gl` counts 8 tokens.
- **Removes:** nothing.
- **Diagnostics:** one new code, `E0010`, in the lexical block. It is the only code this RFC adds.

## Test plan

- **run:** `conformance/name/run-gl.test`, meta `id: name/run-gl`, `rfc: 0011`, `kind: run`. Source `main io{put 1}` (the program of `kernel/put-one` in RFC 0109). Expected: exit 0, stdout `1`. This shows that a `.gl` path runs.
- **compile-error:** `compiler/stage0/src/cli.test.ts`. For each of `prog.txt`, `PROG.GL`, `main.glyph` and `missing.txt`, and each of `check`, `run` and `build` (with `-o out.wasm`), the command gives exit 1, empty standard output, and exactly one stderr line equal to the record in Design 5 with that path as `file`. The conformance runner writes every source to `main.gl`, so these path cases are node tests.
- **unit:** `compiler/stage0/src/source-file.test.ts` covers every case in Design 2.
- **unit:** `compiler/stage0/src/message.test.ts` checks that the Design 5 message passes `checkMessage` with no problem.

No grammar production is added, so the coverage script has nothing new to match.

## Memory allocation

Not applicable. This RFC adds no heap values.

## Open questions

- Whether the language should accept a second extension later. This RFC says no. A later RFC must justify any second suffix.
- The name has not been checked against existing software or trademarks. That needs a network check outside this session.
