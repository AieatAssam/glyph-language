# RFC 0011: The language name

Class: language
Slug: name-v2
Author: designer-min

## Summary

The language is called **Glyph**. Source files end in `.gl`. The compiler is `glyphc`. This RFC adds no grammar, no types and no runtime behaviour. It fixes the name, the source-file rule, and the one diagnostic, `E0010`, that rejects any other path.

## Motivation

`README.md`, `docs/SPEC.md`, `bin/glyphc` and the site already use the name Glyph. Renaming them before any kernel exists costs more than it saves. The check job and the publisher need one fixed suffix to recognise sources, so the suffix is fixed now.

## Design

Normative.

1. The language is named `Glyph`. The spec title is `Glyph`. Names are case-sensitive, and `Glyph` is the only spelling used in the spec.
2. A source file is a path whose last component, the part after the last `/`, ends in `.gl` and has at least one character before `.gl`. The match is case-sensitive. These are source files: `main.gl`, `dir/prog.gl`, `a.b.gl`. These are not: `.gl`, `dir/`, the empty path, `main.gl.bak`, `main.glyph`, `prog.txt`, `PROG.GL`.
3. The compiler executable is `glyphc`. Its subcommands `check`, `run` and `build` are named here. Later RFCs define them.
4. When `glyphc` is given a path that is not a source file, it does not open the file. It writes one JSON Lines record to standard error, as RFC 0004 section 2 defines, and exits with status 1. It writes nothing to standard output. The record has:
   - `code`: `E0010`
   - `severity`: `error`
   - `message`: `source file does not end in .gl`
   - `span`: `{"file": <path as given>, "start": 0, "end": 0, "line": 1, "column": 1}`
   - no `fix`, because renaming the file is the author's choice.
5. `spec/errors.json` contains this entry: `{"code": "E0010", "message": "source file does not end in .gl", "meaning": "the path given is not a source file"}`. The message has a full stop inside the file extension `.gl`. Under RFC 0004 section 2 a full stop inside a file name is not a sentence break, so the message is one sentence and is valid as written.
6. `spec/core/name.md` states rules 1 to 4 in full. `spec/card.md` has the title line `Glyph` and the line `Source: *.gl, compiler glyphc`.

## Alternatives

- **Keep "Glyph" as a codename and choose a name later.** Rejected. It postpones a decision that costs nothing now and leaves the suffix open.
- **Choose another name.** Rejected. Every file and tool would change, and no reason outweighs that cost. A later RFC may rename the language.
- **No suffix rule.** Rejected. Sources must be identifiable by name.
- **Accept `.glyph` as well as `.gl`.** Rejected. A second suffix is a second way to name the same file, which breaks principle 1.
- **A `GLY` code prefix.** Rejected. RFC 0004 fixes the form `E` followed by four digits.

## Cost

Counter output on the files as they now stand, with `sbx python3 -m tools.check.tokens`:

- `spec/core/name.md`: 177 tokens. This is the whole core text for the name.
- `spec/card.md`: 190 tokens for the whole card. The name's part is the title line and the `Source:` line. No separate before-and-after count was taken.
- `spec/errors.json`: 256 tokens for the whole catalogue. The added entry is one line of it.

Adds: the name, the source-file rule, and the code `E0010`.
Removes: nothing.
Grammar: no production is added, so grammar coverage is unchanged.

## Test plan

- run: `conformance/name/run-title.test`. A `main.gl` prints `Glyph`. The output is the `print` of the kernel RFC that defines it.
- compile-error: `compiler/stage0/src/cli.test.ts`, the case that gives the E0010 record and exit status 1 for each of `check`, `run` and `build` with `prog.txt`, `PROG.GL`, `main.glyph` and `missing.txt`. Each case compares the whole record line, requires no `fix`, and requires no ENOENT. The conformance runner writes every source to `main.gl` and cannot name another input, so file-name cases are node tests.
- compile-error: `compiler/stage0/src/e0010.test.ts`. The catalogue has E0010 exactly once, with the message and meaning in rule 5, and the message passes the rules in `compiler/stage0/src/message.ts`.
- unit: `compiler/stage0/src/source-file.test.ts`. The source-file cases in rule 2 give the stated results.

No grammar production is added.

Not applicable. This RFC adds no heap values.

## Open questions

None for this RFC. RFC 0005's address example `main.glyph::add` is not a source path under rule 2. That RFC must change it to `main.gl::add`.
