# RFC 0011: The language name

Class: language
Slug: name-v2
Author: designer-min

## Summary

The language is called **Glyph**. Source files end in `.gl`. The compiler command is `glyphc`. This RFC adds no grammar, no types and no runtime behaviour. It fixes the name in the spec title, the source-file suffix, and one diagnostic code, `E0010`, for a path that is not a source file.

## Motivation

The constitution leaves the name to the agents. The repository already uses Glyph in `README.md`, `docs/SPEC.md`, the compiler command and the site. The cheapest name is the one already in use.

The toolchain needs one fixed suffix to recognise sources before any lexer exists. The file-name check runs before the file is read, so it works when the content is not valid Glyph. Its code sits in the lexical block for that reason.

## Design

Normative.

1. The language name is `Glyph`. The spec title is `Glyph`. `Glyph` is the only spelling of the name in the spec, and names are case-sensitive.
2. A path is a source file when the part after its last `/` ends in `.gl` and has at least one character before `.gl`. The match is case-sensitive. So `main.gl`, `dir/prog.gl` and `a.b.gl` are source files. `main.glyph`, `prog.txt`, `PROG.GL`, `main.gl.bak`, `.gl`, `dir/` and the empty string are not.
3. The compiler executable is `glyphc`. Its subcommands `check`, `run` and `build` are named here and defined by later RFCs.
4. When `glyphc check`, `glyphc run` or `glyphc build` is given a path that is not a source file, it does not read the file. It writes exactly one record to stderr, as JSON Lines per RFC 0004 section 2, writes nothing to stdout, and exits with status 1. The record is:
   - `code`: `E0010`
   - `severity`: `error`
   - `message`: `source file does not end in .gl`
   - `span`: `{"file": <path as given>, "start": 0, "end": 0, "line": 1, "column": 1}`
   - no `fix`. Renaming the file is the author's choice, not a mechanical edit.
5. `E0010` is added to `spec/errors.json` with message `source file does not end in .gl` and meaning `the path given is not a source file`. Codes are never reused.
6. The message in rule 5 passes the RFC 0004 message rules. The full stop in `.gl` is part of a file name, not a sentence break (owner ruling, 2026-11-20).

## Alternatives

- **Keep "Glyph" as a codename and pick a name later.** Rejected. It postpones a decision that costs nothing now and leaves the suffix open.
- **Pick a new name.** Rejected. Every existing file and tool would change. Name collisions were not checked, because the session had no network access. A later RFC may rename the language; renaming is cheap before a release.
- **No suffix rule.** Rejected. Tools need one suffix to find sources.
- **Accept `.glyph` as well as `.gl`.** Rejected. A second suffix is a second way to name the same thing.
- **A `GLY` code prefix.** Rejected. RFC 0004 fixes the form `E` followed by four digits.

## Cost

Counted with `tools/check/tokens.py`:

- The record in Design 4 is 45 tokens. It adds one diagnostic, `E0010`, in the lexical block.
- Spec card: adds the lines `Glyph` and `Source: *.gl, compiler glyphc`, which count 10 tokens in total.
- Core spec: adds the title, the rule in Design 2, the name in Design 3 and a reference to `E0010`. The implementing PR records the counted figure. It is far under the 12,000-token cap.
- Removes: nothing.
- Grammar: no production is added, so grammar coverage is unchanged.

## Test plan

- **run:** `conformance/name/run-title.test`. A `main.gl` that prints `Glyph` with `print`, as defined by the kernel RFC.
- **compile-error (node):** `compiler/stage0/src/cli.test.ts`. For each of `check`, `run` and `build`, and each of `prog.txt`, `PROG.GL`, `main.glyph` and `missing.txt`: stderr is the one record in Design 4 with no `fix`, stdout is empty, the status is 1, and the file is not read.
- **node:** `compiler/stage0/src/source-file.test.ts`. One case for each path listed in Design 2.
- **node:** `compiler/stage0/src/e0010.test.ts`. The catalogue entry in Design 5 and the message rule in Design 6.

No grammar production is added, so the coverage script has nothing new to match.

## Memory allocation

Not applicable. This RFC adds no heap values.

## Open questions

- The conformance runner gives every source file the name `main.gl`. The file-name cases are therefore tested only by the node tests above. A runner that accepts an input file name would allow conformance tests for them.
- A kernel RFC that gives an address example must write it as `main.gl::add`, not `main.glyph::add`, so that it agrees with Design 2.
- Whether a second suffix is ever needed is for a later RFC. That RFC must remove it or justify it.
- The name has not been checked against existing software or trademarks. That needs a network check outside this session.
