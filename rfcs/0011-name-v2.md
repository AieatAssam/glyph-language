# RFC 0011: The language name

Class: language
Slug: name-v2
Author: designer-min

## Summary

The language is called **Glyph**. Source files end in `.gl`. The compiler command is `glyphc`. This RFC adds no grammar, no types and no runtime behaviour. It fixes the name, the source-file suffix, and one diagnostic code for a path that is not a source file.

## Motivation

The name is already used in `README.md`, `docs/SPEC.md`, `bin/glyphc` and the site, so keeping it renames nothing. The check job and the publisher need one fixed suffix to recognise sources. The source-file check runs on the file name before the file is read, so it does not depend on the lexer.

## Design

Normative.

1. The language name is `Glyph`. The title line of `spec/core/name.md` and of `spec/card.md` is `Glyph`. `Glyph` is the only spelling of the name in the spec, and it is case-sensitive.
2. A path is a source file when its last path segment ends in `.gl` and has at least one character before `.gl`. The match is case-sensitive. `main.gl`, `dir/prog.gl` and `a.b.gl` are source files. `main.glyph`, `prog.txt`, `PROG.GL`, `main.gl.bak`, `.gl`, `dir/` and the empty path are not.
3. The compiler executable is `glyphc`. Its subcommands `check`, `run` and `build` are named here and defined by later RFCs.
4. When `glyphc check`, `glyphc run` or `glyphc build` is given a path that is not a source file, it does not open the file. It writes one JSON Lines record to stderr, as RFC 0004 section 2 defines, with:
   - `code`: `E0010`
   - `severity`: `error`
   - `message`: `source file does not end in .gl`
   - `span`: `{"file": <path as given>, "start": 0, "end": 0, "line": 1, "column": 1}`
   - no `fix`, because renaming the file is the author's choice.

   It writes nothing to stdout and exits with status 1.
5. The message is one sentence. A full stop followed by a letter inside a file name, such as in `.gl` or `main.gl`, is part of the name and not a sentence break. So the message passes the one-sentence rule of RFC 0004 section 2, and the message checker must accept it.
6. `E0010` is listed in `spec/errors.json` with message `source file does not end in .gl` and meaning `the path given is not a source file`. Codes are never reused.
7. `spec/core/name.md` states rules 1 to 4. `spec/card.md` gets the two lines `Glyph` and `Source: *.gl, compiler glyphc`.

## Alternatives

- **Keep a codename and decide the name later.** Rejected. The suffix is needed now, and the name costs nothing to fix.
- **Another name.** Rejected. Every existing file and tool would change, and no reason outweighs that cost. A later RFC can rename the language; renaming is cheapest before a release. Collision with other software is not checked here.
- **No suffix rule.** Rejected. The check job and publisher need one suffix.
- **Accept `.glyph` as well.** Rejected. A second suffix is a second way to name one thing, which breaks principle 1. `main.glyph` gets `E0010`.
- **A diagnostic code with another prefix.** Rejected. RFC 0004 fixes `E` followed by four digits.

## Cost

Counted with `tools/check/tokens.py`:

- Core spec: the name section `spec/core/name.md` is 177 tokens. No other core text changes.
- Spec card: the two added lines `Glyph` and `Source: *.gl, compiler glyphc` are 10 tokens. The card as a whole counts 190 tokens against a cap of 2,000.
- Example programs: none. The rule is about file names.
- Grammar: no production is added, so grammar coverage is unchanged.
- Diagnostics: one new code, `E0010`, in the lexical block.

## Test plan

- run: `conformance/name/run-title.test`. A `main.gl` program prints `Glyph` with `print` from the kernel RFC.
- compile-error: `compiler/stage0/src/cli.test.ts`. For each of `prog.txt`, `PROG.GL`, `main.glyph` and `missing.txt`, `check`, `run` and `build` each give exactly the record in Design rule 4, exit with status 1, and do not open the file.
- unit: `compiler/stage0/src/source-file.test.ts` covers every example in Design rule 2.
- unit: `compiler/stage0/src/message.test.ts` covers the message in Design rule 5.

## Memory allocation

Not applicable. This RFC adds no heap values.

## Open questions

- The conformance runner writes every source to `main.gl`, so a conformance-kind compile-error test cannot name a non-`.gl` input. Until the runner can name an input file, the file-name cases are tested by the node tests above. This is a tools change, outside this RFC.
- A second suffix, if ever needed, needs a later RFC that justifies it.
