# Plan: RFC 0113 Keyword and built-in spellings (word-spelling)

RFC 0113 is accepted (frontmatter). It amends RFC 0104 (keyword list, grammar names `wh`, `ret`, `ex`, `put`) and RFC 0109 (statement and declaration text, kernel card). This plan follows RFC 0113 and writes no code. It was checked against this session's scratch copy on 2026-11-27.

## Conflicts and decisions

1. **The keyword table in the tree is RFC 0014, not RFC 0104.** RFC 0113 W1 renames RFC 0104's keywords. Decision: this plan does not edit the RFC 0014 table into a half-way table. Subtask 2 applies W1 to the RFC 0104 table, and it is blocked until RFC 0104 plan subtasks 1 to 6 have written `token.ts`. If they have not, subtask 2 does not start, and the PR says so. Subtasks 1, 3 to 6 do not depend on it.
2. **`token.test.ts` pins superseded words.** Its RFC 0014 list and `keywordKind('print') === null` contradict W1. Decision: subtask 2 replaces those assertions with RFC 0113's list and says so in its PR body. These are node tests, not conformance tests, so the rule against editing in-force conformance tests does not apply.
3. **RFC 0113's `lex/kw-*` ids cannot be `.test` files.** The four ids (`lex/kw-while`, `lex/kw-return`, `lex/kw-example`, `lex/kw-print`) expect a token kind, which no conformance kind states. Decision: they are node tests in `token.test.ts`, with the ids in the test titles. RFC 0104's retirement list names `lex/kw-while`, `lex/kw-return` and `lex/kw-example`. No file with those ids exists in the tree, so nothing is edited on disk.
4. **Card and core text do not yet exist.** W4 names kernel lines in `spec/card.md`. The kernel card is written by RFC 0109 plan subtask 21. Decision: that subtask writes the kernel lines in the W4 spellings. Subtask 6 here checks them, and adds no card text.
5. **Old spellings in other plans.** RFC 0104's Test plan rows (`v6-*`) and RFC 0109's plan rows (`kc-*`, `put-*`) use `put`, `ret`, `wh`, `ex` in their program text. None of those files exists yet. Decision: each subtask that writes such a row writes it in the W2 spelling and keeps the row's id. These are new files. No in-force test is edited.
6. **`fail` stays a keyword.** W6 keeps it, as RFC 0104 plan Conflicts 3 and RFC 0109 plan Conflicts 3 already decided. No subtask here touches it.
7. **Green points.** Each conformance row below is red until the subtask it names lands. The PR body of each subtask lists the rows that are still red, with the subtask that turns each one green. This is the convention of `rfcs/0109.plan.md`.
